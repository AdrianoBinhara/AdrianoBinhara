## Open-source highlights

### [Contador](https://github.com/AdrianoBinhara/contador)
A liquid-glass countdown that lives on the edge of your Mac's screen. Drag it, throw it, and watch it settle into place.

**Swift · SwiftUI · AppKit · macOS**

</a>

### [CommentLoom](https://github.com/AdrianoBinhara/commentloom)
Open-source Instagram Reels comment automation using Meta's official APIs. A private invitation comes first; the link is sent after the person explicitly confirms.

**TypeScript · React · Node.js · MySQL**

### [Swift Onboard Flow Editor](https://github.com/AdrianoBinhara/swift-onboard-flow-editor)
A visual onboarding-flow experiment with editable slides, global styles, and a phone preview. Built on the web with an iOS integration flow.

**TypeScript · React · Vite · Tailwind CSS**
